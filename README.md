# Планстра

**Конструктор бренд-стратегии** — 45 слайдов: от PESTLE и SWOT до
позиционирования, миссии, карты бренда и стратегической канвы голубого океана.

Открытая бета-версия.

## Что это

Одностраничное приложение без сервера. Всё, что вы вводите, хранится в вашем же
браузере (localStorage) и никуда не отправляется. На каждом слайде есть подсказка
«Подробнее» и пример, работает импорт/экспорт Markdown и выгрузка в PDF —
в PDF попадают только отмеченные слайды.

## Как запустить локально

Скачайте `index.html` и откройте в браузере. Больше ничего не нужно.

| Файл | Что это |
|---|---|
| `index.html` | приложение целиком |
| `favicon.svg` | иконка вкладки |
| `og.png` | картинка превью для соцсетей |
| `.nojekyll` | отключает обработку Jekyll на GitHub Pages |
